# Rule-Based Recommendation System

A Python-based recommendation system that provides personalized suggestions based on user preferences and predefined rules.

## Features
- Takes user input and generates recommendations
- Rule-based decision making
- Provides personalized suggestions
- Simple and interactive console application

## Technologies Used
- Python

## Working
1. User enters their preferences
2. The system compares input with predefined rules
3. Suitable recommendations are generated

## How to Run
1. Download or clone the repository
2. Run:

python recommendation_system.py

## Project Purpose
This project demonstrates the working of a basic rule-based expert system and decision-making using predefined conditions.
